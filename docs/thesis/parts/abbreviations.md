# List of Abbreviations and Terms

| Abbreviation / Term | Explanation |
|---|---|
| API | Application Programming Interface |
| CPU | Central Processing Unit |
| CSV | Comma-Separated Values (*Comma-Separated Values*) |
| dB | Decibel — the unit used to express sound pressure level |
| dB(A) | A-weighted Decibel — decibel measurement filtered to match human auditory sensitivity |
| EEST | Eastern European Summer Time (UTC+3) |
| EET | Eastern European Time (UTC+2) |
| EU | European Union |
| FastAPI | A Python web framework for building APIs |
| GPU | Graphics Processing Unit |
| IoT | Internet of Things — network of physical devices embedded with sensors and connectivity |
| IEC | International Electrotechnical Commission |
| ISO | International Organization for Standardization |
| KNN | K-Nearest Neighbours — a spatial interpolation method using geographically proximate sensors |
| LCS | Low-Cost Sensor |
| LoRaWAN | Long Range Wide Area Network — a low-power wireless communication protocol used in IoT deployments |
| MAE | Mean Absolute Error — average of absolute differences between predicted and true values |
| MAR | Missing at Random — missingness that depends on observed data but not on the missing values themselves |
| MCAR | Missing Completely at Random — missingness independent of both observed and missing values |
| MEMS | Micro-Electro-Mechanical Systems — miniaturised sensor technology used in low-cost acoustic devices |
| NB-IoT | Narrowband Internet of Things — a low-power wide-area network standard for IoT devices |
| RMSE | Root Mean Square Error — square root of the average squared differences between predicted and true values |
| RQ | Research Question |
| SPL | Sound Pressure Level — logarithmic measure of effective sound pressure relative to a reference value of 20 μPa, expressed in decibels |
| SQL | Structured Query Language — language used for managing relational databases |
| SQLite | A lightweight, file-based relational database engine |
| TimesFM | Time Series Foundation Model — a pre-trained transformer model developed by Google Research for time-series forecasting |
| UTC | Coordinated Universal Time — the primary international time standard |
| WHO | World Health Organization |
| WiFi | Wireless Fidelity — a wireless local area network technology |
